# Gate 2 游戏性审计

审计日期：2026-08-29

冻结规则：`blockmarket-v1-prototype.2`

验收样本：7 个参考 Bot、100 个公开开发初值、每局 300 区块、每个配对同初值 A/B 双局换边，共 4,200 场。

复现命令：

```bash
uv run --python 3.12 python -m blockmarket matrix \
  --blocks 300 --seeds 100 --output replays/matrix_v2_100x300.json
```

## prototype.1 的失败原因

首版公开参考价几乎直接暴露二阶 Hénon 状态，客户流又过于同质。Bot 可以从公开历史近似反推出下一步，`InventoryAware` 在首轮参考矩阵中对其余策略平均全部占优。这是机制警报，不是调几个固定价差就能解决的问题。

prototype.2 保留稳定二阶基线，但加入由赛后可揭示密钥生成的隐藏有界参考价噪声；客户订单拆成普通与知情订单；每轮只公开 65% 准确的方向信号。由此形成明确代价：窄价差多成交却更容易被知情订单逆向选择，单边信号策略减少毒性但放弃普通流量，对手适应和库存管理又能针对前两者。

## 验收结果

- `strict_dominating_strategies = []`：七个参考策略中没有一个对其他六个都取得严格正的换边平均得分。
- 检测到 8 个严格正收益三策略循环。
- 主要、最容易讲清的循环是 `SignalFollower > TightSpread > OpponentAdaptive > SignalFollower`。

| 优势方 | 劣势方 | 换边平均得分 | 100 初值胜–负 | 最差初值得分 | 最佳初值得分 |
| --- | --- | ---: | ---: | ---: | ---: |
| SignalFollower | TightSpread | +0.030718083332 | 75–25 | -0.082198607802 | +0.152977182164 |
| TightSpread | OpponentAdaptive | +0.246719308682 | 100–0 | +0.145783407172 | +0.382892856304 |
| OpponentAdaptive | SignalFollower | +0.060065141572 | 98–2 | -0.008823244056 | +0.166700514232 |

其余循环与完整 7×7 分数均由矩阵产物中的 `strict_positive_cycles` 和 `scores` 字段机器生成，不靠手工挑选。

## 位置与边界

每个初值均以相同订单流运行 AB/BA 两局。所有配对的未换边位置差绝对值：均值 `0.000741668958`、P95 `0`、最大值 `0.086001398225`。多数局完全无位置差，但离散同价余数仍会产生少量尾部，因此正式排名必须换边，不能把“P95 为零”说成单局绝对公平。

终值价格不受玩家报价或成交价影响，消除了直接拉终值的尾盘操纵；现金、库存和费用约束逐成交检查，阻止越界刷分。恶意动作与数值格式另由 fail-closed 校验和独立复核覆盖。

## 结论

Gate 2 的**工程验收已关闭**：当前参考策略集合与公开开发初值中不存在明显统治策略，并出现跨 100 初值可复现的循环克制。它证明的是原型玩法可继续做封闭测试，不是对全部策略空间的数学证明，也不代表正式赛规已经审批。

后续不得再靠改规则掩盖产品问题。Gate 3 runner 现已允许 Python/TypeScript Bot 直接对局；下一步是在 Gate 4 封闭 Alpha 中观察真实参与者是否发现新统治策略、规则误解或不可接受的位置尾部。
