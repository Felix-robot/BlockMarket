## 6. Alpha 关闭检查

- [ ] 至少 5 名参与者独立完成提交，而不是组织者复制参考 Bot 代交。

- [ ] 参与者能够解释核心成交、知情订单、信号和换边规则。
- [ ] 故障与重跑有记录，没有静默修改提交或种子。
- [ ] 真人策略矩阵已检查统治关系、循环、位置尾部与异常动作。

## 7. 结论

- `PROCEED_TO_GATE_5`：玩法和本地产品验证通过，开始 OCI 隔离、双机复放与压力测试。
